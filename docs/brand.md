# SheetProof 品牌基础

## 命名候选

| 英文名 | 中文名 | 方向 | 结论 |
|---|---|---|---|
| **SheetProof** | **表鉴** | 强调在合并前看清并验证表格变化 | 主方案。专业、克制，能覆盖对比、审阅和合并决策 |
| GridMeld | 格融 | 强调网格数据的汇合 | 含义偏合并，对“审阅差异”的表达较弱 |
| SheetMeld | 表合 | 更接近表格合并 | 描述直接，但辨识度与中文气质不如主方案 |

本次只做了公开网页与软件名称的初步冲突检索，不构成商标或公司名称的法律检索。
`SheetProof` 在当前检索中没有发现直接对应的知名表格软件；发布前若计划商业化，
仍应在目标市场完成商标、域名和应用商店名称核验。

## 主品牌

- 英文名：SheetProof
- 中文名：表鉴
- 英文 Slogan：See every change. Merge with intent.
- 中文介绍语：看清每一处差异，再决定如何合并。

名称里的 “Proof” 不是自动审批或形式化验证承诺，而是产品动作：先把工作簿的
真实语义差异摆在同一个视图中，再由用户选择复制、覆盖、追加、撤销或保存。

## 图标概念

图标由深海军蓝底、左右两张抽象工作表、红绿变化行与中央校验路径构成：

- 左右面板代表旧/当前与目标版本；
- 红与绿沿用应用内 Git 双栏差异语义；
- 中央蓝色校验路径同时表达“核对完成”和“有意识地合并”；
- 大块面与有限细节保证 16–32 px 下仍可识别。

维护源为 `build/appicon.svg`。`scripts/generate-brand-assets.py` 从同一设计参数导出
桌面 PNG、Windows ICO、网站 favicon 与常用尺寸，不依赖在线设计工具。

## 视觉基线

| 角色 | 色值 |
|---|---|
| Ink / 背景 | `#0B1E33` |
| Navy / 品牌底色 | `#123A63` |
| Cobalt / 主操作 | `#2F6FED` |
| Added | `#2DA86B` |
| Removed | `#DE5757` |
| Paper | `#F7FAFD` |

桌面应用与官网都使用系统无衬线字体、克制阴影、清晰细边框和上述语义色；不把
装饰动画、渐变大字或泛化插画作为主要品牌识别。
